## Recorded decisions

- **release.json is generated, never committed.** The pin binds
  repositorySha to HEAD; committing it would make the pin
  self-referential and permanently stale. The operator generates it from
  a clean detached checkout of the public release commit at session
  start (`npm run release:pin`); it is gitignored. This resolves plan
  step 2's scaffold listing against the single-pin-source invariant.
- **The MALFORMED recovery branch (family c) is defense-in-depth.** The
  descriptor is fully validated before anchored-proposal recovery, so
  only the amount-not-found/ambiguous failures (AMOUNT_UNRESOLVED) are
  reachable through the public API today; the MALFORMED wrap guards
  against future protocol changes and is documented as such in its
  commit.
